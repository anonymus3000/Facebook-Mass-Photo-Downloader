# Facebook-Mass-Photo-Downloader
Allows you to mass download photos from a list of facebook links to those photos
(example of links: https://www.facebook.com/photo.php?fbid=1004231194833093&set=pb.100057386652322.-2207520000&type=3)
# How to get links
1. Download chrome extension "Tampermokey"
2. Enable Developer Mode in chrome extension settings
3. Enable "Allow user scripts" in chrome extension settings of "Tampermonkey"
4. Download this Tampermokey script and follow instructions on this page: https://greasyfork.org/en/scripts/559491-facebook-photos-reels-link-collector
# How to Run
1. Download and extract zip into 1 folder
2. Open command line and run: "npm install"
3. Then run: "npm start"
# Recomendations:
- Use no more than 16 parallel pages(after that the increase in parallel pages does NOT give an increase in pages/second (i.e. speed)
- Use 2-3 seconds shortest and longest delay (this really depends on your ping)
